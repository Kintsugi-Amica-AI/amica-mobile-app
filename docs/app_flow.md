# App Flow

1. User signs in or creates an account.
2. User adds trusted emergency contacts.
3. User can start a Smart Journey Timer before travel.
4. If the timer expires without confirmation, Amica prepares an SOS escalation.
5. User can manually trigger SOS with live location at any time.
6. Fake Call can be scheduled as a deterrent.
7. Stealth Voice SOS listens for a configured secret phrase.
8. Scan Before You Ride sends plate OCR results to the backend for vehicle status checks.
