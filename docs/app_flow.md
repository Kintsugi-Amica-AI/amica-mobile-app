# App Flow

1. User signs in or creates an account.
2. User adds trusted emergency contacts.
3. User can start a Smart Journey Timer before travel.
4. If the timer expires without confirmation, Amica prepares an SOS escalation.
5. Before boarding a bus, the user can pick the stop they are getting off at, and Amica alarms when they come within the chosen distance (2 km by default) of it.
6. User can manually trigger SOS with live location at any time.
7. Fake Call can be scheduled as a deterrent.
8. Stealth Voice SOS listens for a configured secret phrase.
9. Scan Before You Ride sends plate OCR results to the backend for vehicle status checks.
